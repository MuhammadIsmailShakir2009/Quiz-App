📚 School Quiz App

A simple and interactive School Quiz Application built to test knowledge through multiple-choice questions. Users can attempt quizzes, select answers, and instantly see their results. The project provides a clean interface and smooth quiz experience.

🚀 Live Demo

👉 Try the App:
https://school-quiz-app.netlify.app/

✨ Features

🧠 Multiple choice quiz questions

⚡ Instant answer checking

📊 Score calculation at the end

🎨 Clean and responsive UI

💻 Runs directly in the browser

🛠️ Technologies Used

HTML5

CSS3

JavaScript

📂 How to Run Locally

Clone the repository

git clone https://github.com/MuhammadIsmailShakir2009/quiz-app.git

Open the project folder.

Run index.html in your browser.
